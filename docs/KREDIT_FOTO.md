# Kredit Foto — Planner Tugas Kuliah

Foto yang digunakan sebagai ilustrasi suasana belajar, bukan foto pribadi mahasiswa.

Keduanya digunakan melalui URL Wikimedia Commons sebagai gambar jaringan (`Image.network`) dan ditampilkan dengan pemotongan visual `BoxFit.cover`. Aplikasi memiliki fallback ikon saat gambar tidak dapat diunduh. Foto **belum disimpan sebagai aset lokal** dalam repository; tampilan foto membutuhkan koneksi internet serta akses yang tidak diblokir ke Wikimedia Commons.
